# paywall-kit

**SaaS 變現漏斗 kit：零依賴 tier-gate 核心（功能閘門/用量配額/升級路徑/原價→特價折扣計算）+ 銷售型方案頁/升級誘導卡/結帳頁 React 模板 + 免費版上限 DB trigger 範本。tier 定義與金流 checkout 注入。** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/paywall-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('paywall-kit');
const x = create({ /* opts */ });
```
